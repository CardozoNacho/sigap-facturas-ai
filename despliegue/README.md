# Recursos de integración

Las migraciones de `sql/` muestran columnas documentales y de comprobante utilizadas por la aplicación Java. Revisarlas contra el esquema destino: esta edición no contiene una conexión a PostgreSQL ni ejecuta cambios de base automáticamente.

La URL del lector y su token se configuran fuera del código. Las fuentes de referencia del automatizador están en `integracion_rcc/`.

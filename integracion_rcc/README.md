# Integración Java y vista del automatizador

Fuentes de referencia del servicio Java, servlet, JSP y JavaScript/CSS de seguimiento. Utilizan modelos y servicios de SIGAP que pertenecen a la aplicación anfitriona y no se incluyen aquí.

El servidor entrega trabajos autorizados al ejecutor y verifica resultados antes de marcar una factura como cargada. Distingue guardado, existencia previa, reconciliación y revisión. La interfaz muestra el folio y el motivo de revisión.

`RCCServicioTest.java` utiliza ejemplos sintéticos para comprobar reglas cuando se integra con las dependencias Java correspondientes.
